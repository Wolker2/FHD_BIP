# FHD_BIP — схема событий игрового моста

Игровой слой не имеет API-ключей и не выходит в интернет. Он формирует короткий JSON и передаёт его `FHD_BIPBridge.dll`.

Минимальная форма:

```json
{"type":"state","system":"Солнце","planet":"Земля","credits":1450200,"fuel":18,"hull_percent":72}
```

Для точной навигационной информации используется авторитетный снимок текущей системы:

```json
{"type":"system_context","system":"Солнце","system_id":17,"planet":"Земля","planets":[{"id":101,"name":"Земля","type":"inhabited"},{"id":102,"name":"Марс"}],"stations":[{"id":201,"name":"Военная база","type":"military","race":"Люди"}]}
```

Расширенный снимок v0.8.0 может передавать только реально доступные значения:

```json
{"type":"state","system":"Солнце","planet":"Земля","map_position":{"x":12,"y":34},"fuel":17,"hull_percent":72,"credits":1450200,"game_date":"01.01.3300","ship_status":{"status":"flight","cargo":18,"cargo_capacity":40},"equipment":[{"id":301,"name":"Двигатель","condition_percent":88}],"quests":[{"id":401,"name":"Доставка","days_left":4}],"messages":[{"text":"Получено задание","important":true}],"nearby_objects":[{"id":501,"name":"Рейнджер","type":"ship","distance":24}]}
```

Для безопасных команд игровой слой передаёт точные каталоги и список активных интеграций:

```json
{"type":"capabilities","integrations":["FHD_Autopilot","FHD_Trade"],"known_systems":[{"id":23,"name":"Альтаир","open":true}],"trade_goods":[{"id":4,"name":"Медицина"}]}
```

Результат команды возвращается только с исходным `command_id`:

```json
{"type":"command_result","command_id":"...","action":"trade.search_and_mark","status":"completed","message":"Поиск завершён, метка FHD_Trade установлена"}
```

Поле, которого игра не знает, нужно не передавать либо передавать как `null`.
Нельзя подставлять примерное или выдуманное значение.

При смене системы список `planets`/`stations` предыдущей системы автоматически очищается, пока мост не пришлёт новый точный список. БИПу запрещено дополнять эти списки выдуманными объектами.

Рекомендуемые типы:

- `state` — периодический компактный снимок существенных чисел;
- `location` — смена системы/планеты/станции/формы;
- `system_context` — точное положение плюс полный доступный список планет и станций текущей системы;
- `combat` — начало/конец боя, число видимых угроз, критическое повреждение;
- `trade` — фактическая покупка/продажа и итог сделки;
- `quest` — принятие, прогресс, срок, успех/провал;
- `equipment` — поломка/ремонт важного оборудования;
- `death` — гибель/загрузка после гибели;
- `custom` — безопасное событие интеграции другого FHD-мода.
- `capabilities` — точные каталоги известных систем/товаров и доступные интеграции;
- `command_result` — подтверждённый игрой статус ранее поставленной команды.

Правила качества:

1. Не слать событие каждый кадр/тик без изменения — только изменение или редкий heartbeat.
2. Не передавать сырые указатели/handles движка.
3. Не включать API-ключи, пути пользователя, персональные данные и содержимое произвольных файлов.
4. JSON не больше 64 KiB; нормальная цель — до 2 KiB.
5. Любое действие ИИ проходит allowlist-валидатор; `queued` не считается успехом до `command_result status=completed`.
