FHD_BIP v0.8.0 game commands — УСТАНОВКА И ЗАПУСК
==========================================

1. Распакуйте архив в КОРЕНЬ игры Space Rangers HD.

Правильный результат:
<ИГРА>\Mods\FHD_MODS\FHD_BIP\ModuleInfo.txt
<ИГРА>\Mods\FHD_MODS\FHD_BIP\START_FHD_BIP.bat
<ИГРА>\Mods\FHD_MODS\FHD_BIP\COMPANION\

2. Запустите START_FHD_BIP.bat.

3. Если готового FHD_BIP_v0.8.0.exe рядом нет, при первом запуске потребуется:
   - Windows 10/11 x64;
   - Python 3.11 или новее с компонентом Python Launcher;
   - интернет для установки трёх библиотек клиента.

4. В окне БИПа выберите нейросеть, настройте её профиль, сохраните API key
   или токен (для LM Studio не нужен) и нажмите «ЗАПУСТИТЬ БИП».

5. Для защиты от случайных звуков оставьте чувствительность микрофона
   «Низкая — меньше ложных срабатываний». Если БИП перестал слышать тихую речь,
   переключите её на «Средняя».

6. Оставьте включённым «Работать только когда активно окно игры». После запуска
   БИПа переключитесь в Space Rangers HD. В остальных окнах микрофон и голос
   помощника автоматически приостанавливаются.

7. «Индикатор микрофона» показывает уровень сигнала, фактический порог и состояние «ГОЛОС/Тишина». Ползунок «Точная настройка микрофона» применяется сразу: значение вправо (+dB) повышает чувствительность, влево уменьшает.

8. Ползунок «Громкость голоса БИПа» регулирует только помощника от 0 до 100%.
   Изменение применяется сразу и сохраняется кнопкой «СОХРАНИТЬ НАСТРОЙКИ».

9. «Инициативность» управляет частотой самостоятельных реплик:
   - Низкая: редко, примерно раз в 4–6 минут;
   - Средняя: примерно раз в 1,5–2,5 минуты;
   - Высокая: примерно раз в 50–90 секунд;
   - Болтун: примерно раз в 25–50 секунд.
   Это интервалы проверок, а не обязательных реплик: если ничего интересного
   не произошло, БИП сохраняет тишину.

10. «Разрешать голосом прерывать реплику БИПа» по умолчанию выключено. Так
    случайный звук не обрывает ответ. Включайте только если хотите перебивать
    БИП голосом. При выключенном перебивании говорите после окончания его
    реплики: затем микрофон снова принимается автоматически.

11. Кнопка «ДИАГНОСТИКА» показывает соединение, микрофон, обнаружение игры,
    наличие точных данных, текущую систему/планету и вызовы игровых функций.

НАСТРОЙКА НЕЙРОСЕТЕЙ
--------------------

1. В «Настроить профиль» выберите Gemini, GPT (OpenAI), GigaChat, YandexGPT, DeepSeek,
   Qwen, Cloud.ru, LM Studio или пользовательский OpenAI-compatible API.
2. Для каждого используемого профиля заполните:
   - точное название модели;
   - полный endpoint до /chat/completions;
   - флаг изображений, только если модель действительно поддерживает vision;
   - API key или готовый Bearer token кнопкой «Сохранить ключ».
3. Затем выберите основную нейросеть и до трёх резервов слева направо.
4. Оставьте включённым автоматическое переключение при ошибке API.

LM STUDIO
---------

1. Установите LM Studio, загрузите модель и запустите Local Server.
2. Стандартный endpoint уже заполнен:
   http://localhost:1234/v1/chat/completions
3. В профиле LM Studio укажите ID реально загруженной модели.
4. API key для обычного локального LM Studio не нужен.
5. Выберите «Локальная модель — LM Studio» основной или последним резервом.

ГОЛОС TTS WINDOWS
-----------------

Для текстовых провайдеров включите «Озвучивать текстовые AI через голос Windows»
и выберите «Голос TTS Windows». В список попадают только голоса, установленные
в Windows. Пункт «По умолчанию» использует системный голос. Настройка «Голос
Gemini Live» относится только к нативному голосу Gemini.

ГОЛОС GPT (OPENAI)
------------------

Профиль «GPT (OpenAI)» использует отдельный OpenAI TTS. В поле «Голос GPT
(OpenAI)» можно выбрать `alloy`, `ash`, `ballad`, `coral`, `echo`, `fable`,
`nova`, `onyx`, `sage`, `shimmer`, `verse`, `marin` или `cedar`. Для GPT нужен
отдельный API key OpenAI; подписка ChatGPT сама по себе не является API key.

ГОЛОСОВЫЕ ВОЗМОЖНОСТИ
---------------------

- Gemini Live: микрофон, распознавание речи, потоковый экран и нативный голос.
- GPT (OpenAI): ввод текста, игровые события, последний кадр для vision-моделей
  и голосовой ответ выбранным голосом OpenAI TTS.
- Остальные провайдеры: ввод текста, игровые события, последний кадр для
  vision-моделей и озвучка ответа системным голосом Windows.
- Отдельный STT для остальных провайдеров пока не включён; микрофон для них
  автоматически отключается, чтобы интерфейс не создавал ложное впечатление.

Старые самостоятельно собранные EXE можно удалить: версия 0.8.0 запускает
только FHD_BIP_v0.8.0.exe либо актуальный исходный код.

Самостоятельный режим работает без FHD_Trade, FHD_Autopilot и других модов.
Команды маршрута и торговли требуют совместимых игровых интеграций FHD_Autopilot/FHD_Trade,
которые читают %LOCALAPPDATA%\FHD_BIP\bridge\commands.jsonl и возвращают command_result.

ВАЖНО
------
Текущая стабильная сборка видит игру через захват окна и слышит игрока через
микрофон. Непроверенный RScript/DLL-мост внутрь игры не включён, чтобы не
создавать падения 32-битного процесса Space Rangers HD.
