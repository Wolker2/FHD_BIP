# Игровой слой FHD_BIP v0.8.0

Эта папка — исходная заготовка самостоятельного игрового моста. Он **не зависит** от FHD_Trade, FHD_Autopilot или других модов.

Текущая граница готовности:

- нативная DLL уже имеет простой ABI `FHDBIP_Version / FHDBIP_EmitEventW / FHDBIP_ClearQueue`;
- входящие данные игры читаются из `%LOCALAPPDATA%\FHD_BIP\bridge\events.jsonl`;
- исходящие allowlist-команды BIP пишутся в `%LOCALAPPDATA%\FHD_BIP\bridge\commands.jsonl`;
- доступны команды открытия карты, фокуса точной системы, маршрута FHD_Autopilot и поиска/метки FHD_Trade;
- игровой потребитель обязан вернуть `command_result`; состояние `queued` не считается выполнением;
- сетевого кода и API-ключа внутри игры нет;
- перед публикацией скомпилированного `Mod_FHD_BIP.scr` нужно один раз подтвердить точную сигнатуру `ImportedFunction`/calling convention на целевой сборке SRHD. Непроверенную сигнатуру в релизный SCR намеренно не помещаем, чтобы не создавать краш 32-битного процесса игры.

Даже без этого игрового слоя программа-компаньон работает самостоятельно: захват окна + микрофон + Gemini Live + голос + память. Запускать её нужно через `Mods\FHD_MODS\FHD_BIP\START_FHD_BIP.bat`.
