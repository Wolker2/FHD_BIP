# FHD_BIP v0.8.0 game commands — Бортовой Интеллектуальный Помощник

`FHD_BIP` — голосовой ИИ-напарник для Space Rangers HD / «Космические рейнджеры HD».

Главный принцип проекта: **БИП работает самостоятельно и не требует FHD_Trade, FHD_Autopilot, FHD_RangerLog или любых других наших модов.** Интеграции лишь дают ему дополнительные точные данные.

## Что уже есть в v0.8.0

- Gemini Live по WebSocket;
- GPT (OpenAI) через Chat Completions с голосовым выводом OpenAI TTS;
- двусторонний голосовой разговор;
- микрофон PCM 16 kHz;
- воспроизведение нативного аудио Gemini;
- захват только окна игры и отправка JPEG-кадров не чаще 1 кадра/с;
- русский интерфейс;
- имя помощника по умолчанию `БИП`, которое можно изменить;
- отдельное поле «как обращаться к игроку»;
- 6 характеров и 4 уровня инициативности;
- локальная SQLite-память;
- Gemini API key в Windows Credential Manager — не в текстовом конфиге;
- необязательная локальная очередь игровых событий;
- исходник собственного x86 `FHD_BIPBridge.dll` без сетевого кода;
- автоматическая миграция настроек/памяти/ключа со старого имени `FHD_AICompanion`;
- единый Provider Manager с основной моделью, тремя резервами и автоматическим переключением;
- профили Gemini, GPT (OpenAI), GigaChat, YandexGPT, DeepSeek, Qwen, Cloud.ru, LM Studio и любого OpenAI-compatible API;
- отдельные model/endpoint/vision/API key для каждого профиля;
- ожидание `setupComplete` перед передачей микрофона и экрана;
- автоматическое переподключение и возобновление Live-сессии;
- сжатие контекста для длительной работы;
- ограниченная очередь микрофона без бесконтрольного роста памяти;
- очистка звуковой очереди, когда игрок перебивает помощника.
- локальный шумовой порог: короткий щелчок или тихий фон не отправляются в Gemini;
- низкая серверная чувствительность начала речи с защитной задержкой 150 мс;
- завершение голосового потока после устойчивой паузы;
- настраиваемая чувствительность микрофона;
- приостановка микрофона, кадров, игровых событий и голоса БИПа, когда окно игры не активно.
- отдельная сохраняемая регулировка громкости голоса БИПа от 0 до 100% с применением во время разговора.
- самостоятельные контекстные реплики по свежему кадру игры и игровым событиям;
- чтение или краткий пересказ видимых информационных сообщений;
- анализ ситуации, предупреждения, советы, шутки и подколы в соответствии с выбранным характером;
- четыре реально различающихся частоты инициативности;
- программная проверка уместности: помощник не обязан комментировать каждую проверку;
- свежий кадр до 1920×1080 перед проактивной проверкой для более уверенного чтения игрового текста.
- авторитетное состояние игры: координаты галакарты, корабль, корпус, топливо, деньги, дата, оборудование, задания, сообщения и ближайшие объекты;
- 11 функций чтения точных игровых данных; неизвестное всегда возвращается как `known=false`, `value=null`;
- 4 allowlist-команды: открыть карту, найти точную систему, проложить маршрут и запустить FHD_Autopilot, найти товар и поставить метку FHD_Trade;
- точная проверка систем и товаров по каталогам текущей партии; выдуманные и неоднозначные названия не исполняются;
- отдельная очередь `commands.jsonl` и подтверждение `command_result`: передача команды не выдаётся за её успешное выполнение;
- отдельный фильтр важных событий с cooldown для срочных и уместных самостоятельных реплик;
- настройка перебивания: по умолчанию случайный звук не может оборвать голос БИПа;
- диагностическое окно с состоянием API, голоса, микрофона, игры, игровых данных и функций;
- OpenAI-compatible chat completions с function calling, историей, точным игровым контекстом и опциональным кадром для vision-модели;
- локальный LM Studio по умолчанию проверяется на `http://localhost:1234/v1/models`;
- текстовые провайдеры озвучиваются системным голосом Windows с применением общей громкости БИПа.
- для текстовых провайдеров можно выбрать любой установленный Windows SAPI TTS-голос или оставить системный по умолчанию;
- GPT дополнительно позволяет выбрать голос OpenAI TTS: `alloy`, `ash`, `ballad`, `coral`, `echo`, `fable`, `nova`, `onyx`, `sage`, `shimmer`, `verse`, `marin`, `cedar`;

## Самостоятельные реплики

Период задаёт момент, когда БИП оценивает свежий кадр и решает, стоит ли говорить:

| Инициативность | Интервал проверки |
| --- | --- |
| Низкая | 4–6 минут |
| Средняя | 100–160 секунд |
| Высокая | 50–90 секунд |
| Болтун | 25–50 секунд |

Проверка не гарантирует реплику. Если на экране ничего нового или уместного нет, БИП молчит. Он также не запускает проактивную реплику вне активного окна игры, во время речи игрока и сразу после собственной реплики.

## Самостоятельный режим

Для основной работы достаточно:

1. запустить Space Rangers HD;
2. запустить `Mods\FHD_MODS\FHD_BIP\START_FHD_BIP.bat`;
3. выбрать AI-провайдера, настроить его профиль и сохранить ключ/токен, если он требуется;
4. нажать `ЗАПУСТИТЬ БИП`.

При первом запуске без готового EXE установщик создаёт отдельное окружение Python в папке `COMPANION` и ставит только необходимые библиотеки. Требуются Windows, Python 3.11+ и интернет. После установки БИП запускается той же кнопкой `START_FHD_BIP.bat`.

Даже без игрового моста БИП получает контекст из игрового окна и голоса пользователя. Структурированные игровые события — улучшение точности, а не обязательная зависимость.

## Правильный путь установки игрового мода

Папка игрового мода должна находиться **только** здесь:

```text
<папка игры>\Mods\FHD_MODS\FHD_BIP\
```

То есть `FHD_BIP` нельзя класть напрямую в `Mods`. В исходной сборке готовое дерево для копирования находится здесь:

```text
game_mod_source\Mods\FHD_MODS\FHD_BIP\
```

После копирования структура должна начинаться так:

```text
Space Rangers HD\
└── Mods\
    └── FHD_MODS\
        └── FHD_BIP\
            ├── ModuleInfo.txt
            ├── START_FHD_BIP.bat
            ├── COMPANION\
            └── SOURCE\
```

## Разработка / запуск из исходников

Требуется Windows и Python 3.11+. Из каталога `COMPANION`:

```bat
set PYTHONPATH=%CD%\src
py -3 -m fhd_bip
```

Сборка одного EXE:

```bat
BUILD_EXE.bat
```

Результат:

```text
COMPANION\dist\FHD_BIP_v0.8.0.exe
```

## Текущий честный статус игрового моста

Контракт событий подготовлен, но скомпилированный RScript/DLL-мост намеренно не выдаётся за «готовый», пока на целевой сборке SRHD не подтверждена точная ABI-сигнатура `ImportedFunction`. Ошибка calling convention в 32-битной игре может привести к падению процесса, поэтому этот шаг должен пройти отдельный smoke test.

Это **не мешает самостоятельной работе БИПа** через экран и голос.

В установочную сборку v0.8.0 намеренно не входят фиктивные пустые `CFG`, `SCR` или DLL. Клиентская очередь команд реализована, но фактическое нажатие/маршрут/метка требуют совместимых игровых потребителей FHD_Autopilot и FHD_Trade. Каталог `SOURCE` содержит точный контракт для этих интеграций.


## Точность игрового контекста v0.8.0

БИП не имеет права придумывать игровые сведения. Визуальная информация используется только для анализа того, что действительно видно. Для гарантированной точности собственный игровой мост передаёт `[GAME_CONTEXT]`, а Gemini запрашивает конкретное значение одной из 11 функций. Если мост не передал значение, функция возвращает `null`, и БИП обязан честно сказать, что данных нет.

Экран передаётся из клиентской области окна игры до 1920x1080 при качестве JPEG 85, поэтому мелкий текст информационных панелей сохраняется лучше, чем в v0.5.1.

## Микрофон v0.8.0

Три режима стали немного чувствительнее. Дополнительно есть ползунок `Точная настройка микрофона` от -6 до +10 dB: положительное значение позволяет ловить более тихую речь, отрицательное сильнее отсекает шум. Начните с 0 dB и меняйте небольшими шагами.


## Индикатор и ручная чувствительность v0.8.0

Индикатор показывает текущий уровень микрофона в dBFS, реальный порог SpeechGate и состояние распознавания голоса. Ползунок тонкой настройки теперь влияет одновременно на фиксированный и адаптивный шумовой порог, поэтому его изменение действительно меняет чувствительность во время работы. Положительное значение повышает чувствительность, отрицательное уменьшает.

## Провайдеры

В v0.8.0 Gemini Live остаётся нативным двусторонним голосовым режимом. Профиль GPT (OpenAI) использует `chat/completions`, а затем OpenAI TTS с выбранным голосом. Остальные профили используют рабочий общий протокол OpenAI-compatible `chat/completions`: текст можно вводить в нижней строке, ответ отображается и озвучивается через выбранный Windows SAPI-голос. Если модель поддерживает vision, включите этот флаг в её профиле — к запросу будет приложен последний кадр игры.

Для GigaChat в поле ключа нужен готовый Bearer access token, а не OAuth authorization key. Для YandexGPT, Cloud.ru и других сервисов укажите их OpenAI-compatible endpoint, точное имя модели и требуемый токен. Если сервис не предоставляет OpenAI-compatible `chat/completions`, его нативный протокол этой сборкой не поддерживается.

Микрофон и потоковый голос без отдельного STT работают только с Gemini Live. GPT имеет голосовой вывод через OpenAI TTS, но вопросы игрока в этой сборке вводятся текстом. У остальных текстовых провайдеров БИП говорит через Windows, а вопросы игрока также вводятся текстом. Это честное ограничение: распознавание речи не подменяется фиктивным модулем.

### Настройка профилей и резервов

1. В «Настроить профиль» выберите сервис.
2. Укажите точное имя модели и полный endpoint, заканчивающийся на `/chat/completions`.
3. Если это vision-модель, включите передачу изображения.
4. Сохраните ключ/токен. Он хранится отдельно для каждого профиля.
5. Выберите основную нейросеть и до трёх резервов в порядке переключения.
6. Оставьте включённым автоматическое переключение.

Никогда не вставляйте ключ в URL endpoint. Удалённые endpoint принимаются только по HTTPS; обычный HTTP разрешён лишь для локального сервера на этом компьютере.

Режим «Автоматически» перебирает настроенные сервисы в порядке Gemini → GPT → DeepSeek → Qwen → GigaChat → YandexGPT → Cloud.ru → LM Studio → пользовательский API. Не настроенный профиль пропускается. При переключении новый адаптер получает тот же системный prompt, характер, последний точный игровой контекст, последний кадр и краткий недавний разговор.

## Function Calling

Функции чтения: `get_current_system`, `get_current_planet`, `get_known_planets`, `get_galaxy_map_position`, `get_ship_status`, `get_ship_fuel`, `get_equipment_status`, `get_current_quests`, `get_game_messages`, `get_player_credits`, `get_nearby_objects`.

Команды управления: `open_galaxy_map`, `find_system_on_map`, `start_autopilot_route`, `search_trade_good_and_mark`. Команды работают только через allowlist, проверяют точное имя по `known_systems`/`trade_goods` и возвращают `queued`. Успех подтверждается только событием `command_result` от игры.
