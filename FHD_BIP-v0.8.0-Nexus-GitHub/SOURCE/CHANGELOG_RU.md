# FHD_BIP v0.7.1 MULTI-PROVIDER

## Прокрутка интерфейса
- Добавлена вертикальная прокрутка всего окна настроек.
- Колесо мыши прокручивает общий интерфейс.
- Журнал диалога имеет собственный вертикальный scrollbar и прокручивается отдельно.
- Нижние настройки и кнопки теперь доступны на небольших разрешениях экрана.


- Реализован рабочий универсальный OpenAI-compatible адаптер `chat/completions` без привязки core к конкретному сервису.
- В интерфейс добавлены: Автоматически, Gemini, GigaChat, YandexGPT, DeepSeek, Qwen, Cloud.ru, LM Studio и пользовательский OpenAI-compatible API.
- Каждый профиль хранит собственные model, endpoint, vision-флаг и отдельный ключ/токен Windows Credential Manager.
- Добавлены три упорядоченных резервных провайдера и автоматическое переключение после ошибки.
- При переключении сохраняются характер, системный prompt, точный игровой контекст, последний кадр и короткий недавний разговор.
- OpenAI-compatible адаптер поддерживает стандартный function calling и возвращает результаты тех же 11 read-only игровых функций.
- Для GigaChat добавлен отдельный совместимый диалект `functions/function_call`, а не фиктивная отправка неподдерживаемого поля `tools`.
- Vision-модель может получить последний кадр игры в стандартном `image_url` data URI.
- LM Studio работает без API-ключа и при подключении реально проверяется через `/v1/models`.
- Ответы текстовых провайдеров озвучиваются через Windows SAPI; ползунок громкости применяется к этому голосу.
- В UI добавлен список реально установленных Windows SAPI-голосов и сохранение выбранного TTS-голоса; голос Gemini Live выбирается отдельно.
- Добавлен отдельный профиль GPT (OpenAI): Chat Completions + OpenAI TTS с выбором 13 официальных голосов.
- Gemini Live сохраняет полный двусторонний голос. Для текстовых провайдеров микрофон честно отключён до появления отдельного STT-адаптера.
- Добавлен интеграционный тест локального HTTP API: выбор резерва, два запроса с tool calling и финальный ответ.

# FHD_BIP v0.6.0 STABLE CORE

- Добавлены 11 read-only функций Gemini Live для точных игровых данных: система, планета, планеты системы, координаты, корабль, топливо, оборудование, задания, сообщения, деньги и ближайшие объекты.
- Функция возвращает `known=false` и `value=null`, если игровой мост не передал значение. Модель явно обязана не додумывать его.
- Авторитетный игровой контекст расширен: координаты галакарты, корпус, топливо, деньги, дата, оборудование, задания, сообщения и ближайшие объекты.
- При смене системы очищаются все привязанные к старой системе объекты и координаты.
- Добавлен фильтр важных событий с cooldown: низкое топливо, критический корпус, бой, поломка, важное сообщение и значимое изменение задания могут вызвать короткую самостоятельную реплику.
- Добавлена настройка перебивания. По умолчанию `NO_INTERRUPTION`: случайный звук не обрывает голос БИПа, а микрофон не передаёт обратно собственный звук БИПа. После окончания реплики обычная речь снова принимается автоматически.
- Добавлена кнопка диагностики: API, STT/TTS, микрофон, игра, точные данные, система/планета, tools, ошибка и latency.
- Создан единый Provider Manager. Неработающие провайдеры не показываются как доступные; Gemini Live остаётся единственным проверенным голосовым адаптером этой сборки.
- Формат setup/tool response сверён с официальным Live API. Поле `proactivity`, ранее вызывавшее ошибку 1007, не возвращено.
- Добавлены автоматические тесты контекста, tools, cooldown, громкости, чувствительности и протокола Gemini.

# FHD_BIP — изменения

## v0.5.1 stable

- Исправлена ошибка запуска Gemini Live `1007 invalid frame payload data: Unknown name "proactivity" at "setup"`.
- Неподдерживаемое конкретным сервером поле `setup.proactivity` удалено из обязательной конфигурации сессии.
- Самостоятельные реплики сохранены: ими управляют локальный таймер инициативности, свежий кадр, игровые события и системный промпт БИПа.

## v0.5 stable

- Добавлен проактивный цикл: БИП время от времени самостоятельно оценивает происходящее и решает, нужно ли заговорить.
- Перед проверкой передаётся свежий кадр игры до 1600×900 для чтения информационных сообщений.
- Добавлена программная проверка уместности самостоятельной реплики.
- Добавлены самостоятельные анализ, предупреждения, советы, атмосферные реплики, шутки и подколы.
- Формулировка каждой реплики обязана соответствовать выбранному характеру БИПа.
- Уровни инициативности получили разные случайные интервалы и больше не являются только текстовым пожеланием в промпте.
- Проактивная реплика не запускается вне игры, во время речи игрока или сразу после предыдущего ответа.
- Если содержательного повода нет, БИП сохраняет тишину и не озвучивает служебную проверку.

## v0.4.2 stable

- Добавлен ползунок громкости голоса БИПа от 0 до 100%.
- Новая громкость применяется сразу, даже во время текущего разговора.
- Значение сохраняется в настройках и восстанавливается при следующем запуске.
- 0% полностью отключает звук помощника, не отключая микрофон и соединение.

## v0.4.1 stable

- Исправлен слишком строгий фильтр v0.4, из-за которого БИП мог полностью перестать слышать обычную речь.
- Порог каждого уровня чувствительности снижен до рабочего диапазона.
- Для начала передачи достаточно 0,2 секунды устойчивой речи вместо 0,3 секунды.
- Добавлена адаптация к постоянному тихому фону без подавления нормального голоса.
- Защитная задержка Gemini уменьшена до 150 мс.
- В журнал добавлены статусы активности окна и первое подтверждение «Голос обнаружен — БИП слушает».

## v0.4 stable

- Добавлен локальный шумовой порог микрофона с тремя уровнями чувствительности.
- Одиночные короткие звуки больше не открывают голосовую реплику.
- Gemini Live переведён на низкую чувствительность начала речи и защитную задержку 300 мс.
- После устойчивой паузы аудиопоток корректно завершается через `audioStreamEnd`.

- Не добавлялись полный запрет прерываний, тематическое ограничение ответов и режим push-to-talk.
- Версионный EXE `FHD_BIP_v0.4.exe` не позволяет случайно запустить самостоятельно собранный EXE от старой версии.
